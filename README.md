# Desafio Tecnico FullStack Nivel Básico

##  Tecnologias utilizadas

- HTML
- CSS
- Vscode
- JavaScript
- Foi utilizada uma i.a (Deepseek) para desenvolver as funções JavaScript

  
## Como executar o projeto

1. Clone este repositório ou faça o download do arquivo.zip do projeto
2. Abra o aplicativo Visual Code.
3. Abra a pasta do projeto e clique no arquivo do html



## Aprendizados

Durante o desenvolvimento, foram aplicados conceitos de programação, organização de código, desenvolvimento front - end e boas práticas de desenvolvimento de software.
